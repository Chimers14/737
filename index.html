    Browsers block pages from reading file:/// paths, so a pasted file:///G:/…pdf can't be opened directly. Paste it anyway and the app will show you the file name to drag in. Web links work only if the host allows cross-origin downloads (Google Drive viewer links usually don't — download the PDF and drop it in).
